# Data Dictionary

This directory contains **summary statistics only** — no individual patient data, no raw imaging, no protected health information (PHI). All files are de-identified in accordance with the original IRB approval.

---

## Files

### `nomogram_params.json`
Nomogram construction parameters (Harrell method):

| Key | Type | Meaning |
|---|---|---|
| `intercept` | float | Logistic intercept β₀ = -1.555 |
| `features` | object | Per-feature coefficient and z-score normalization parameters |
| `features.MeshVolume.beta` | float | β = -1.167 (shape family) |
| `features.MeshVolume.mu` | float | Mean for z-score (1,292,587) |
| `features.MeshVolume.sd` | float | SD for z-score (217,217) |
| `features.DependenceVariance.beta` | float | β = -0.468 (GLCM family) |
| `features.DependenceVariance.mu` | float | Mean for z-score (10.225) |
| `features.DependenceVariance.sd` | float | SD for z-score (1.967) |
| `points_range` | [int, int] | Per-variable points range [0, 100] |
| `total_points_range` | [int, int] | Total points range [0, 200] |
| `probability_range` | [float, float] | Predicted probability range [0.007, 0.707] |

### `roc_curves.json`
ROC curve coordinates (FPR, TPR) for each of the 4 models, plus calibration curve data.

---

### `ambiguous_resolved.json`
Feature disambiguation map. When multiple PyRadiomics features share a name across families (e.g., "Contrast" appears in GLCM and NGTDM), this file records which family was used. Used for replicability of the feature extraction step.

## What is NOT in this directory (and why)

- ❌ No `patient_name_mapping.json` — held privately by the corresponding author
- ❌ No `merged_60.json` / `baseline_60.json` — contain patient names as keys
- ❌ No `data_with_patient_id.xlsx` — contains patient names in first column
- ❌ No raw DICOM, RTSTRUCT, RTPLAN, RTDOSE files — too large + contain PHI
- ❌ No IRB application documents — contain institutional identifiers
- ❌ No `Results_文字稿.md` (Chinese manuscript draft) — mentions excluded patients by name
- ❌ No `.workbuddy/` memory logs — may contain patient names
