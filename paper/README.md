# Paper

This directory is intentionally empty at the time of the initial release.

## Why no manuscript yet?

The associated paper has been submitted to *Radiotherapy and Oncology* (IF ≈ 6). Per standard publishing ethics and the journal's policy on prior publication:

1. **Pre-peer-review manuscript** should not be publicly distributed before editorial decision.
2. **Accepted manuscript** (post peer review) is typically subject to the journal's copyright transfer; a link to the publisher's version is preferred.
3. **Final published version** (Version of Record) is the canonical citation; the publisher normally archives this on ScienceDirect.

## What will be added when, and where

| Stage | Where to find it | When |
|---|---|---|
| Submitted (under review) | (not public) | Now |
| Accepted | Publisher's "Articles in Press" (ScienceDirect) | After acceptance |
| Published (Version of Record) | Publisher's issue (ScienceDirect) + PubMed indexing | After typesetting |
| Open access version | This `paper/` directory (if permitted by journal) | Optional, post-publication |

## What IS public now

The **analysis code** (in `scripts/`) and the **summary statistics** (in `data/` and `results/`) are public. This is sufficient for reproducibility of all numerical claims in the manuscript. Once the paper is published, the README will be updated with the DOI.
